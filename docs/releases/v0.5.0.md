## Arcana V0.5.0 업데이트

- 추가: 채팅에서 웹 탐색
  - 주소를 붙여넣으면 그 페이지를 읽고 제목·요약·소제목·링크를 보여줌
  - "○○ 검색해줘", "인터넷에서 ○○ 찾아줘" → 채팅 안에 검색 결과 + 1등 페이지 요약
  - 대화하다가 모르는 말이 나오면 알아서 인터넷에서 찾아봄
  - 모든 결과에 출처(사이트, 주소) 표시, 링크는 눌러서 브라우저로 열 수 있음
  - 기본 검색: 위키백과(한·영) + DuckDuckGo 요약 / 설정에 Brave Search API 키를 넣으면 일반 웹 전체 검색
- 추가: 학습 탭 탐색 범위 확대 — 한국어·영어·일본어 위키백과 + 일반 웹사이트
  - 사이트 규칙(robots.txt)을 지키고, 같은 사이트는 10초 이상 간격, 사이트당 하루 100페이지까지만
  - 성인·도박·불법 사이트, 로그인·결제 페이지, 파일 다운로드는 건너뜀 (차단 목록은 설정에서 추가 가능)
  - 글 전체가 아니라 제목·짧은 요약·주소만 저장
- 변경: 지식 질문에서 위키백과에 없으면 인터넷 검색으로 찾아봄

## Arcana V0.5.0 Update

- Added: web browsing in chat
  - Paste a URL and Arcana reads the page: title, summary, headings and links
  - "search ○○" / "find ○○ on the internet" → results inside the chat plus a summary of the top page
  - When an unfamiliar message comes up in conversation, Arcana looks it up on the web by itself
  - Every result shows its source (site and URL); links open in your browser
  - Default search: Wikipedia (ko/en) + DuckDuckGo abstracts / add a Brave Search API key in settings for full web search
- Added: wider exploration in the Learning tab — Korean, English and Japanese Wikipedia plus general websites
  - Follows robots.txt, waits at least 10 s between pages on the same site, max 100 pages per site per day
  - Skips adult/gambling/illegal sites, login/payment pages and file downloads (add your own blocklist in settings)
  - Stores only the title, a short summary and the URL, not whole pages
- Changed: knowledge questions fall back to a web search when Wikipedia has no article
