## Arcana V0.7.0 업데이트

- 변경: 친구끼리 나눈 일상 대화 학습 데이터를 제거하고, 그 데이터로 학습한 대화 모델도 앱에서 뺌
  - 대화 모델이 없을 때는 잡담에 대답을 지어내지 않고, 인터넷에서 찾아보거나 학습 탭에 질문을 남김
  - 직접 가르쳐 준 대답(/Teach, 👎+더 좋은 대답)은 그대로 사용
- 추가: 공책으로 학습하기 (`training\공책으로_학습하기.bat`)
  - 1단계: 학습 탭에서 공부한 위키백과 문서로 한국어 사전학습
  - 2단계: 대화 데이터로 말하는 법 학습
  - 그래픽카드가 있으면 큰 모델(약 2,600만), 없으면 작은 모델(약 200만)
- 추가: 학습 탭 `/Train` (학습 창 열기), `/Reload` (새로 학습한 대화 모델을 앱 재시작 없이 적용)
- 변경: 대화 모델은 앱에 내장하지 않고 `%APPDATA%\Arcana\models` 에서 불러옴
- 변경: 명령 모델을 대화 데이터 없이 다시 학습 (동작 명령 안전장치는 그대로)

## Arcana V0.7.0 Update

- Changed: removed the casual friend-to-friend conversation training data and the chat model trained on it
  - Without a chat model, Arcana doesn't make up replies to small talk; it searches the web or leaves a question in the Learning tab
  - Replies you taught (/Teach, 👎 + better reply) still work
- Added: train from your notes (`training\공책으로_학습하기.bat`)
  - Stage 1: Korean pretraining on the Wikipedia articles studied in the Learning tab
  - Stage 2: learning to talk from conversation data
  - Larger model (~26M) with an NVIDIA GPU, small model (~2M) otherwise
- Added: Learning tab `/Train` (opens the training window) and `/Reload` (applies a newly trained chat model without restarting)
- Changed: the chat model is no longer built into the app; it is loaded from `%APPDATA%\Arcana\models`
- Changed: command model retrained without the conversation data (action-word safety guard unchanged)
