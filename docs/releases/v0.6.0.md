## Arcana V0.6.0 업데이트

- 변경: 대화 모델을 실제 사람 대화 데이터로 새로 학습 (대화 2,288개 → 대답을 합니다체로 바꾼 대화 쌍 2,577개)
  - 기존 템플릿 데이터는 대화 모델 학습에서 제외
- 추가: `training/convert_dialogue.py` — "A: … / B: …" 형식 대화 파일을 학습 데이터로 변환 (대답은 반말 → 합니다체 자동 변환)
- 추가: 안전장치 — 앱 끄기·켜기, 화면 잠금, 볼륨 같은 동작은 문장에 그 동작 말("꺼", "켜", "잠가" 등)이 있을 때만 실행
  - "어제 잠 못 잤어?"가 화면 잠금으로, "디코 들어와"가 디스코드 끄기로 처리되던 문제 수정
- 변경: 자연스럽지 않은 대답 후보는 버리고, 자신 없으면 지어내지 않고 인터넷 검색·학습 탭 질문으로 넘어감

## Arcana V0.6.0 Update

- Changed: the chat model is retrained on real human conversation data (2,288 conversations → 2,577 message/reply pairs with replies converted to formal Korean)
  - The old template data is no longer used for the chat model
- Added: `training/convert_dialogue.py` — converts "A: … / B: …" conversation files into training data (replies converted from casual to formal speech)
- Added: safety guard — actions like closing/opening apps, locking the screen or changing volume only run when the sentence contains an action word ("끄다", "켜다", "잠그다" …)
  - Fixed "Didn't you sleep last night?" locking the screen and "Join Discord when you're done" closing Discord
- Changed: unnatural reply candidates are discarded; when unsure, Arcana no longer makes something up and falls back to a web search and a Learning-tab question
