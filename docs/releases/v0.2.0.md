## Arcana V0.2.0 업데이트

- 추가: Arcana 대화 모델 — 처음부터 직접 만들고 학습시킨 생성형 모델 (약 200만 파라미터)
  - 명령이 아닌 말("배고파", "오늘 너무 피곤해", "롤 졌어" 등)에 직접 대답을 만들어냄
  - 그래픽카드로 학습한 큰 모델(`%APPDATA%\Arcana\models`)이 있으면 자동으로 그걸 사용
- 변경: Arcana 말투를 합니다체로 변경
- 변경: 명령 모델이 잡담을 명령으로 착각하는 경우 줄임
- 변경: 대답을 만드는 동안 창이 멈추지 않음

## Arcana V0.2.0 Update

- Added: Arcana chat model — a generative model built and trained from scratch (~2M parameters)
  - Generates its own replies to non-command messages ("I'm hungry", "I'm so tired today", etc.)
  - Automatically uses a larger GPU-trained model if one is placed in `%APPDATA%\Arcana\models`
- Changed: Arcana now speaks in formal Korean (합니다체)
- Changed: command model mistakes casual chat for commands less often
- Changed: window no longer freezes while a reply is being generated
