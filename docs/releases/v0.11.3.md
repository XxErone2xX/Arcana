## Arcana V0.11.3 업데이트

- 되돌림: v0.11.2 의 "막히면 천천히 읽기"
- 수정: 여러 일꾼이 한 사이트를 동시에 읽다가 갑자기 공부가 멈추던 문제
  - 원인 1: 한 사이트에서 3번 실패하면 그날은 그 사이트를 통째로 포기했음. 일꾼 10명이 동시에 읽으면 잠깐의 연결 끊김만으로도 순식간에 3번이 차서, 한 사이트만 공부할 땐 공부가 멈춘 것처럼 됐음
  - 원인 2: 연결 실패가 5번 이어지면 "인터넷이 끊겼다"고 보고 모든 일꾼이 몇 분씩 쉬었는데, 한 사이트만 읽을 땐 그 사이트 실패만으로도 이렇게 됐음
  - 이제: 연달아 실패한 사이트는 포기하지 않고 잠깐(20초부터) 쉬었다가 다시 읽음. 동시에 여러 번 실패해도 한 번으로 침. 성공하면 바로 풀림
  - 실패한 주소는 버리지 않고 한 번 더 시도
  - "인터넷이 끊겼다"는 서로 다른 사이트 3곳 이상이 연달아 실패할 때만

## Arcana V0.11.3 Update

- Reverted: v0.11.2's "slow down when blocked"
- Fixed: studying suddenly stopped when many workers read one site at the same time
  - Cause 1: after 3 failures on a site, Arcana gave up on it for the rest of the day; with 10 workers, a brief connection hiccup reached 3 failures instantly, so single-site studying looked stuck
  - Cause 2: 5 connection failures in a row were treated as "the internet is down" and every worker paused for minutes, even when only that one site was failing
  - Now: a site with repeated failures is paused briefly (from 20 seconds) instead of abandoned; simultaneous failures count once, and the pause lifts as soon as a page loads
  - Failed addresses are retried once instead of being dropped
  - "Internet is down" is only assumed when 3 or more different sites fail in a row
