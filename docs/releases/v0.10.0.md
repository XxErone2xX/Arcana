## Arcana V0.10.0 업데이트

- 수정: 대화 모델을 학습하고 적용해도 거의 모든 말에 "아직 잘 모르는 말입니다"라고만 하던 문제
  - 원인: 대답을 고르는 기준이 너무 엄격해서(자연스러움 0.85, 닮은 정도 0.5), 실제로 학습한 모델이 만든 대답을 전부 버리고 있었음
  - 실제 모델에 맞춰 기준 조정: 자연스러움 0.72, 닮은 정도 0.25. 대답을 만들 때 조금 더 신중하게 (온도 0.6, 후보 글자 8개)
  - 설정 파일의 `chat_min_fluency`, `chat_min_familiarity` 로 직접 조절 가능
- 추가: 대답 다듬기
  - 중간에 끊긴 꼬리는 버리고 완성된 문장까지만, 길면 앞 2~3문장만
  - 같은 말을 되풀이하는 대답, 조사로 시작하는(앞이 잘린) 대답은 버림
- 수정: 명령으로 잘못 알아듣던 말
  - "화면이 안 켜져요", "앱이 자꾸 꺼져"처럼 상태를 말하는 건 프로그램 켜기·끄기로 보지 않음
  - "와이파이가 자꾸 끊겨"처럼 묻는 말이 없으면 "와이파이가 뭐야" 같은 지식 질문으로 보지 않음

## Arcana V0.10.0 Update

- Fixed: even with a trained chat model applied, Arcana answered almost everything with "I don't know that yet"
  - Cause: the reply filters were too strict (fluency 0.85, familiarity 0.5) and threw away every reply a real trained model produced
  - Thresholds retuned for real models: fluency 0.72, familiarity 0.25; replies are generated a little more carefully (temperature 0.6, top 8 characters)
  - Adjustable via `chat_min_fluency` and `chat_min_familiarity` in the settings file
- Added: reply cleanup
  - Cut off unfinished trailing text and keep only complete sentences (the first 2–3 if long)
  - Drop replies that repeat the same words or start mid-sentence with a particle
- Fixed: sentences mistaken for commands
  - Describing a state, such as "the screen won't turn on" or "the app keeps closing", is no longer treated as opening or closing a program
  - Without a question word, "Wi-Fi keeps dropping" is no longer treated as a knowledge question like "What is Wi-Fi?"
