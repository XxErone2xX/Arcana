## Arcana V0.10.4 업데이트

한 사이트에서만 공부할 때(`/Start only`) 금방 "더 읽을 곳이 없다"고 멈추던 문제를 고치고, 바뀌는 사이트도 따라가게 함.

- 수정: 오래 공부해서 대기열이 가득 찬 PC에서는 새로 찾은 링크가 버려지던 문제 → 한 사이트만 공부할 땐 그 사이트 링크를 맨 앞에, 한 페이지에서 최대 60개까지 넣음 (예전엔 3개)
- 추가: 사이트맵 — 페이지에 다른 곳으로 가는 링크가 없어도, 사이트가 공개한 페이지 목록(sitemap.xml)에서 아직 안 읽은 페이지를 찾아 계속 공부 (하루 한 번 확인)
- 추가: 로딩 화면 대응 — 처음엔 "로딩 중…"만 보이고 자바스크립트로 내용을 채우는 사이트
  - 페이지 안에 숨어 있는 데이터(JSON-LD 본문, Next.js 데이터 등)에서 글을 꺼내 읽음
  - 그래도 비어 있으면 조금 뒤에 두 번까지 다시 시도
- 추가: 바뀐 내용 따라가기 — 읽을 새 페이지가 없으면 하루 넘게 지난 페이지를 다시 확인해서, 내용이 바뀌었으면 새 내용을 저장 ("○○ (바뀐 내용)")
- 변경: 더 읽을 곳이 없을 때 그 이유를 구체적으로 알려 줌 (접근 거부·자동 수집 차단, 너무 자주 읽음, 로딩 화면에서 안 바뀜 등)
- 변경: 수집 규칙을 안 지키는 설정이면 nofollow 표시가 있는 페이지의 링크도 따라감
- 변경: /Start (링크) 를 하면 그 사이트의 오늘 실패 기록을 지우고 다시 시도

## Arcana V0.10.4 Update

Fixes single-site studying (`/Start only`) stopping early with "nothing more to read", and keeps up with sites that change.

- Fixed: on PCs that had studied for a long time, the full queue dropped newly found links → in single-site mode that site's links go to the front, up to 60 per page (previously 3)
- Added: sitemaps — even if pages don't link anywhere new, unread pages are found in the site's published page list (sitemap.xml), checked once a day
- Added: handling for loading screens — sites that first show only "Loading…" and fill in content with JavaScript
  - Text is pulled from data embedded in the page (JSON-LD article body, Next.js data, etc.)
  - If it is still empty, it retries up to two more times a little later
- Added: following changes — when there are no new pages, pages read more than a day ago are checked again and new content is saved if they changed ("… (changed)")
- Changed: when nothing is left to read, the Learning tab gives the specific reason (access denied/blocked crawler, reading too often, stuck on a loading screen, etc.)
- Changed: with crawling rules turned off, links on nofollow pages are followed too
- Changed: /Start (link) clears today's failure record for that site and tries again
