## Arcana V0.1.0 업데이트

- 첫 Rust 버전 출시
- 처음부터 만든 트랜스포머 추론 엔진 (Rust, 외부 AI 라이브러리 없음)

- 기능: 프로그램 켜기/끄기, 타이머, 시간·날짜, 구글·유튜브 검색, 볼륨, 스크린샷, 화면 잠금, 컴퓨터 끄기, 메모

## Arcana V0.1.0 Update

- First Rust release
- Transformer inference engine written from scratch in Rust (no external AI libraries)
- Runs as a single Arcana.exe (no Python install needed)
- Auto-updates from GitHub on launch
- Features: open/close apps, timers, time & date, Google/YouTube search, volume, screenshot, lock screen, shutdown, memos
