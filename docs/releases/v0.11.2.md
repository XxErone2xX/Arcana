## Arcana V0.11.2 업데이트

- 수정: 한 사이트만 빠르게 읽다가 사이트가 막으면 아무 말 없이 멈춘 것처럼 보이던 문제
  - 사이트가 막으면(HTTP 403·429·503) 학습 탭에 바로 이유를 알려 줌
  - 막은 사이트는 스스로 천천히 읽음: 막힐 때마다 그 사이트만 간격을 두 배로 (0.5초 → 최대 60초), 잘 읽히면 다시 조금씩 빠르게
  - `/Status` 에 그 사이트 상태 표시

## Arcana V0.11.2 Update

- Fixed: when reading a single site quickly and the site started blocking, studying looked silently stuck
  - When a site blocks (HTTP 403, 429 or 503), the Learning tab now says why right away
  - Arcana slows down on that site by itself: each block doubles the gap for that site only (0.5 s up to 60 s), and it speeds back up gradually once pages load again
  - `/Status` shows that site's current status
