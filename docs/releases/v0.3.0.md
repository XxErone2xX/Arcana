## Arcana V0.3.0 업데이트

- 추가: 학습 탭
  - `/Start` 하면 위키백과를 조금씩 읽으며 스스로 공부 (앱을 다시 켜도 이어서 공부, `/Stop`으로 멈춤)
  - 모르는 게 생기면 질문함: 뜻이 여러 개인 말, 위키백과에 없는 말, 대화에서 처음 들은 말
  - 질문에 대답해 주면 바로 기억해서 대화 탭에서 사용
  - `/Status`, `/Skip`, `/Teach 말 = 대답`, `/Help` 명령
- 추가: 지식 질문 — "블랙홀이 뭐야", "세종대왕은 누구야" (모르면 위키백과에서 찾아서 기억, 출처 표시)
- 변경: 처음 보는 말에는 대답을 지어내지 않고 솔직하게 모른다고 한 뒤 학습 탭에 질문을 남김

## Arcana V0.3.0 Update

- Added: Learning tab
  - `/Start` makes Arcana study Wikipedia little by little on its own (resumes after restart, `/Stop` to pause)
  - Asks you when it doesn't know something: ambiguous words, things missing from Wikipedia, unfamiliar chat messages
  - Remembers your answers right away and uses them in the chat tab
  - Commands: `/Status`, `/Skip`, `/Teach phrase = reply`, `/Help`
- Added: knowledge questions — "What is a black hole?", "Who is King Sejong?" (looks it up on Wikipedia if unknown, remembers it, shows the source)
- Changed: for unfamiliar messages Arcana no longer makes up a reply; it says it doesn't know and leaves a question in the Learning tab
