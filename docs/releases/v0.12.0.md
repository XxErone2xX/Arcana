## Arcana V0.12.0 업데이트

### 외부 AI API 연결
- 설정 → 모델 → **외부 AI** 에서 다른 AI의 API를 쓸 수 있습니다.
  - OpenAI 호환 (ChatGPT, OpenRouter, Groq, DeepSeek, 내 PC의 Ollama·LM Studio 등 — 주소만 바꾸면 됨)
  - Anthropic (Claude)
  - Google Gemini
- **언제 쓸까요**: "Arcana가 모르는 말만"(기본) 또는 "대화는 전부".
- 앱 열기·끄기, 타이머, 메모 같은 명령은 언제나 Arcana가 직접 처리합니다.
- 최근 대화 몇 개를 같이 보내서 앞뒤 맥락을 이어 갑니다.
- 외부 AI가 만든 대답에는 작은 출처 표시가 붙고, Arcana 학습 재료(👍/👎, 대화 학습)로는 쓰지 않습니다.
- "연결 시험" 버튼으로 키와 모델 이름이 맞는지 바로 확인할 수 있습니다. 키는 이 PC의 설정 파일에만 저장됩니다.

### 한 사이트 공부 개선
- 한 사이트만 공부할 때 질문·기사 같은 글 페이지를 먼저 읽고, 목록·태그·프로필 페이지는 뒤로 미룹니다.
- 목록 페이지는 링크를 찾는 데만 쓰고 공책에는 저장하지 않습니다. (지식iN에서 읽은 페이지의 3분의 2가 목록이었음)

## Arcana V0.12.0 Update

### External AI APIs
- Settings → Model → **External AI**: use another AI's API (OpenAI-compatible incl. OpenRouter/Groq/Ollama/LM Studio, Anthropic Claude, Google Gemini).
- Mode: only for things Arcana doesn't know (default), or all conversation. PC commands are always handled by Arcana.
- Recent turns are sent for context. Replies are labeled with their source and are never used as Arcana training data.
- "Test connection" button; the key is stored only in the local config file.

### Single-site study
- Article/question pages are read first; list, tag and profile pages are queued last and used only to find links, not saved as notes.
