## Arcana V0.8.1 업데이트

- 변경: 빠른 호출 기본 단축키를 `Shift+A` → `Alt+Shift+A` 로 바꿈 (다른 프로그램에서 대문자 A 를 입력할 때 Arcana가 열리지 않게)
  - 이미 `Shift+A` 로 쓰고 있었다면 자동으로 바뀜. 설정 → 빠른 호출에서 다른 키로 바꿀 수 있음

---

## Arcana V0.8.1 Update

- Changed: the default quick-call shortcut is now `Alt+Shift+A` instead of `Shift+A` (so typing a capital A in other programs no longer opens Arcana)
  - If you were using `Shift+A`, it is switched automatically. You can pick another key in Settings → Quick call
