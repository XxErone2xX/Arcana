## Arcana V0.9.9 업데이트

- 변경: 켤 때마다 자동 업데이트
  - 앱을 켜자마자 새 버전을 확인하고, 있으면 바로 받아서 새 버전으로 다시 켬 ("업데이트 중" 화면 표시)
  - 모델·공책을 불러오는 것과 따로 돌아가서, 켜지는 속도와 상관없이 빠르게 확인함
  - 설정 → 일반 → 자동 업데이트를 끄면 직접 "업데이트 확인"을 누를 때만 업데이트

## Arcana V0.9.9 Update

- Changed: automatic update on every launch
  - The app checks for a new version as soon as it starts; if there is one, it downloads it and restarts into the new version (showing an "updating" screen)
  - Runs separately from loading the models and notes, so the check happens quickly no matter how long startup takes
  - Turning off Settings → General → Auto update means updates happen only when you press "Check for updates"
