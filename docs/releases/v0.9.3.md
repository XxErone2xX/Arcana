## Arcana V0.9.3 업데이트

- 추가: 이어서 학습 — 대화 모델을 매번 처음부터 만들지 않고, 지난번 모델에서 이어서 새 재료만 더 배움
  - 절반은 새 문서, 절반은 예전 문서 복습 (예전에 배운 걸 잊지 않게)
  - 새로 배울 양에 맞춰 학습 횟수를 줄임 → 자동 학습이 훨씬 빨리 끝남
  - 새 글자가 생기면 그 글자만 새로 추가 (예전 글자는 그대로)
  - 모델 크기가 바뀌었으면(그래픽카드 변경 등) 처음부터 학습. `--fresh` 로 직접 처음부터 할 수도 있음
- 추가: 학습 재료 다듬기
  - 같은 문서 중복 제거, 여러 사이트에 반복되는 줄(메뉴·저작권 문구 등) 제거
  - 주소, 너무 짧은 줄, 한국어가 아닌 줄, ㅋㅋㅋㅋㅋ 같은 반복 정리
  - 위키백과의 "같이 보기", "각주", "외부 링크" 등 목록 부분 제외
  - 대화 데이터도 같은 쌍 중복 제거
- 변경: 모델 백업은 최근 3개만 남기고 오래된 것은 자동으로 지움

## Arcana V0.9.3 Update

- Added: continued training — instead of rebuilding the chat model from scratch every time, it continues from the previous model and learns only the new material
  - Half new documents, half review of older ones (so it doesn't forget)
  - The number of steps scales with how much is new, so automatic training finishes much faster
  - New characters are added without changing existing ones
  - Trains from scratch if the model size changed (e.g. a different GPU); `--fresh` forces a fresh start
- Added: training-data cleanup
  - Removes duplicate documents and lines repeated across many pages (menus, copyright notices, etc.)
  - Cleans up URLs, very short lines, non-Korean lines and long character repeats
  - Skips Wikipedia list sections such as "See also", "References" and "External links"
  - Duplicate conversation pairs are removed too
- Changed: only the 3 most recent model backups are kept; older ones are deleted automatically
