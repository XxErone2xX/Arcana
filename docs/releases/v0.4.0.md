## Arcana V0.4.0 업데이트

- 추가: 피드백 학습 (3단계)
  - 대화 대답마다 👍/👎 버튼, 👎를 누르면 더 좋은 대답을 알려 줄 수 있음
  - 대답 후보를 여러 개 만들고 지금까지 받은 피드백으로 제일 좋은 대답을 고름 (👎 받은 대답은 다시 안 함)
  - `training\피드백_학습하기.bat`: 모인 피드백으로 대화 모델을 다시 학습 (DPO 방식)
- 수정: 처음 보는 단어가 들어간 문장("새 모니터 샀어" 등)을 모르는 말로 잘못 판단하던 문제

## Arcana V0.4.0 Update

- Added: feedback learning (stage 3)
  - 👍/👎 buttons on every chat reply; after 👎 you can type a better reply
  - Generates several candidate replies and picks the best one using the feedback so far (never repeats a 👎 reply)
  - `training\피드백_학습하기.bat`: retrains the chat model on collected feedback (DPO)
- Fixed: sentences containing new words (e.g. "I bought a new monitor") were wrongly treated as unfamiliar
