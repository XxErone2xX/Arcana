## Arcana V0.8.0 업데이트

- 추가: 빠른 호출 — 어느 화면에서든 `Shift+A` 를 누르면 Arcana를 바로 부를 수 있음 (설정에서 단축키 변경 가능)
  - 화면 위아래가 파랑·보라 물결로 일렁이고, 아래에 입력하면 위에서 Arcana가 대답
  - 입력하는 동안에는 위쪽이, 대답하는 동안에는 아래쪽이 연한 검정으로 가라앉음
  - `Esc` 또는 빈 곳을 누르면 취소
  - Arcana 창에 글을 쓰는 동안에는 단축키가 잠깐 꺼져서 대문자 A 도 그대로 입력됨
- 추가: 대화 맥락 기억 — "디코 켜줘" → "그거 꺼줘", "아까 검색한 거 다시 찾아줘", "그거 더 알려줘", "한 번 더"
- 추가: 메모리 — "내 이름은 ○○야", "내 생일은 ○○", "나는 ○○ 좋아해", "기억해: ○○" 를 오래 기억
  - "내 이름 뭐야?", "나에 대해 뭐 알아?" 에 대답, 인사할 때 이름으로 부름
  - 설정 → 메모리에서 보기·추가·삭제·끄기
- 추가: 컨테이너 메모리 — 대화 기록을 저장해서 앱을 다시 켜도 맥락이 이어짐
  - 설정에서 10MB ~ 10GB 로 크기 조절, 가득 차면 오래된 것부터 지움, 사용량 표시, 지우기
- 추가: 모델 탭 생각 수치 (1~5단계) — 오른쪽일수록 더 많은 대답을 만들어 보고 더 신중하게 고름
  - 가장 오른쪽 = PrimeThink: 스스로 완벽하다고 판단할 때까지 계속 다시 생각함 (최대 30초)
  - 대화 모델이 있을 때 잡담 대답에 적용됨
- 변경: 대답이 한 글자씩 써짐 (누르면 바로 전부 표시)
- 변경: 입력창에서 `Shift+Enter` 로 줄바꿈, 내용에 맞춰 입력창이 늘어남
- 변경: 스크롤바를 가늘게, 마우스를 올렸을 때만 보이게. 위로 올려서 읽는 중에는 자동으로 내려가지 않음
- 변경: 메뉴를 설정 창(설정 · 모델 · 정보)으로 바꿈

## Arcana V0.8.0 Update

- Added: quick call — press `Shift+A` anywhere to summon Arcana (the shortcut can be changed in Settings)
  - Blue and purple waves ripple along the top and bottom of the screen; type at the bottom and Arcana answers at the top
  - While you type, the top side settles into a soft black; while Arcana answers, the bottom side does
  - `Esc` or clicking an empty area cancels
  - The shortcut is paused while you type in the Arcana window, so a capital A still types normally there
- Added: conversation context — "디코 켜줘" → "그거 꺼줘", "아까 검색한 거 다시 찾아줘", "그거 더 알려줘", "한 번 더"
- Added: Memory — remembers your name, birthday, likes and dislikes, and "기억해: …" notes
  - Answers "내 이름 뭐야?" / "나에 대해 뭐 알아?" and greets you by name
  - View, add, delete or turn off in Settings → Memory
- Added: Container memory — conversation history is saved so context carries over after a restart
  - Size adjustable from 10 MB to 10 GB in Settings; oldest entries are removed when full; usage display and clear button
- Added: Thinking level (1–5) in the Model tab — higher levels try more replies and choose more carefully
  - The far right is PrimeThink: keeps rethinking until it judges its own reply to be perfect (up to 30 seconds)
  - Applies to small-talk replies when a chat model is installed
- Changed: replies now type out one character at a time (click to show the whole reply)
- Changed: `Shift+Enter` inserts a new line; the input box grows with its content
- Changed: thin scrollbars that appear only on hover; the view no longer jumps to the bottom while you are reading earlier messages
- Changed: the menu is now a Settings window (Settings · Model · About)
