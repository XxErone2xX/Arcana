## Arcana V0.5.1 업데이트

- 변경: 학습 탭 탐색 쿨타임 제거 — 쉬지 않고 계속 읽음 (기존 설정도 자동으로 0초로 바뀜)
  - 사이트가 robots.txt 로 직접 정해 둔 간격(Crawl-delay)과 사이트당 하루 100페이지 제한은 유지
- 추가: `/` 를 입력하면 입력창 위에 명령어 목록 표시 (글자로 걸러짐, ↑↓ 이동, Enter·Tab 선택, Esc 닫기)
  - 학습 탭: /Start, /Stop, /Status, /Skip, /Teach, /Help
  - 대화 탭: /Learn, /Clear, /Settings, /Help

## Arcana V0.5.1 Update

- Changed: removed the exploration cooldown in the Learning tab — Arcana now reads continuously (existing settings are migrated to 0 s automatically)
  - Still honors a site's own robots.txt Crawl-delay and the 100-pages-per-site daily limit
- Added: typing `/` shows a command list above the input (filters as you type, ↑↓ to move, Enter/Tab to pick, Esc to close)
  - Learning tab: /Start, /Stop, /Status, /Skip, /Teach, /Help
  - Chat tab: /Learn, /Clear, /Settings, /Help
