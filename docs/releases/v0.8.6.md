## Arcana V0.8.6 업데이트

- 수정: 빠른 호출(Alt+Shift+A)을 부르자마자 입력하면 Windows 경고음이 나면서 첫 글자가 안 들어가던 문제
  - 원인: 단축키의 Alt 에서 손을 뗄 때 Windows가 창 메뉴를 켜서 다음 글자 하나를 가져감
  - 단축키를 누르는 순간 아무 기능 없는 키를 한 번 보내서 창 메뉴가 켜지지 않게 함
- 수정: 창이 뜬 직후 입력창에 포커스가 늦게 가던 문제 (창을 먼저 띄우고 포커스를 준 뒤 준비, 필요하면 한 번 더 포커스)

## Arcana V0.8.6 Update

- Fixed: typing right after calling quick call (Alt+Shift+A) made Windows beep and dropped the first character
  - Cause: releasing Alt from the shortcut made Windows open the window menu, which swallowed the next key
  - A no-op key is now sent the moment the shortcut fires so the window menu doesn't open
- Fixed: the input box sometimes got focus late right after the window appeared (the window is now shown and focused first, with one retry if needed)
