## Arcana V0.5.3 업데이트

- 수정: 학습 중 페이지 하나가 문제(리다이렉트 반복, 꺼진 서버 등)일 때 학습 전체가 5분 멈추던 문제
  - 문제 있는 페이지는 건너뛰고 바로 다음으로 넘어감
  - 같은 사이트에서 3번 연속 실패하면 그 사이트는 그날 건너뜀
  - 여러 사이트에서 연속 5번 실패할 때만 인터넷 문제로 보고 잠시 쉼
- 변경: 리다이렉트 허용 횟수 5번 → 10번, 리다이렉트 반복 오류를 알기 쉽게 표시

## Arcana V0.5.3 Update

- Fixed: one broken page (redirect loop, dead server, ...) paused all learning for 5 minutes
  - Broken pages are skipped and Arcana moves straight on
  - A site that fails 3 times in a row is skipped for the rest of the day
  - Learning pauses only after 5 consecutive failures across sites (a real connection problem)
- Changed: allows up to 10 redirects (was 5) and explains redirect-loop errors clearly
