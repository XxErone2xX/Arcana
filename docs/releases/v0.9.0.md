## Arcana V0.9.0 업데이트

- 추가: 자동 학습 — 학습 탭에서 /Start 로 켜 두면, 재료가 모였을 때 PC를 쓰지 않는 동안 대화 모델을 알아서 학습하고 바로 적용함
  - 마지막 학습 뒤 새 문서 2,000개 또는 새 대화 30쌍이 모이면 학습 (처음에는 재료만 충분하면 바로)
  - PC를 10분 이상 안 쓰고 있을 때만 학습 (설정 → 모델에서 1~60분으로 조절, 끄기 가능)
  - 보이지 않는 창에서 낮은 우선순위로 실행, 끝나면 /Reload 없이 바로 적용
  - 재료가 부족하면 새 재료가 생길 때까지 다시 시도하지 않음. 학습 기록: `%APPDATA%\Arcana\training\auto.log`
  - /Status 에 자동 학습 상태 표시
- 변경: 학습 도구를 앱 안에 넣음 — 레포를 따로 받지 않아도 /Train 이 바로 됨
  - 학습 도구는 `%APPDATA%\Arcana\training` 에 자동으로 풀림. 대화 데이터(.jsonl)는 그 안의 `data` 폴더에 넣으면 됨
  - 처음 학습할 때 Python 이 필요함 (python.org, Add to PATH 체크). PyTorch 는 자동으로 설치

## Arcana V0.9.0 Update

- Added: automatic training — while studying is on (/Start in the Learning tab), Arcana trains its chat model on its own when enough material has built up and you aren't using the PC, then applies it right away
  - Trains after 2,000 new documents or 30 new conversation pairs since the last run (the first time, as soon as there is enough material)
  - Only trains after the PC has been idle for 10 minutes (adjustable from 1 to 60 minutes, or off, in Settings → Model)
  - Runs in a hidden window at low priority and applies the new model without /Reload
  - If there isn't enough material, it waits for new material before trying again. Log: `%APPDATA%\Arcana\training\auto.log`
  - /Status shows the automatic training status
- Changed: the training tools are now built into the app, so /Train works without downloading the repository
  - They are unpacked to `%APPDATA%\Arcana\training`; put conversation data (.jsonl) in its `data` folder
  - Python is required for the first training run (python.org, check "Add to PATH"); PyTorch is installed automatically
