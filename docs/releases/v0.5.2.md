## Arcana V0.5.2 업데이트

- 수정: 일부 PC에서 "인터넷에 연결할 수 없습니다"가 뜨던 문제
  - 보안 연결에 윈도우 인증서 저장소를 사용 (백신·보안 프로그램이 HTTPS를 검사하는 PC 대응), 실패하면 다른 방식으로 한 번 더 시도
  - 윈도우 프록시 설정을 따름
  - 실패하면 원인을 자세히 표시 (DNS, 보안 연결, 방화벽, 시간 초과 등)
- 추가: 학습 탭 `/Diag` — 인터넷 연결 진단 (사이트별, 연결 방식별 결과)
- 변경: 대답이 더 다양해지고 신중해짐
  - 생각 깊이: 대답 후보를 8개 만들어서 고름 (설정 `think_depth`, 최대 32)
  - 최근에 한 대답과 비슷하면 피함, 자연스러운 문장과 조금 더 긴 대답을 우대
  - 설정: `chat_temperature`(다양성), `chat_top_k`, `prefer_long_replies`

## Arcana V0.5.2 Update

- Fixed: "Cannot connect to the internet" on some PCs
  - Uses the Windows certificate store for secure connections (works with antivirus/security software that inspects HTTPS) and retries with the built-in certificates if that fails
  - Follows the Windows proxy settings
  - Shows the actual cause on failure (DNS, TLS, firewall, timeout, ...)
- Added: `/Diag` in the Learning tab — internet connection diagnostics per site and per connection method
- Changed: replies are more varied and more carefully chosen
  - Think depth: generates 8 candidate replies and picks the best (setting `think_depth`, up to 32)
  - Avoids repeating recent replies, prefers fluent and slightly longer replies
  - Settings: `chat_temperature` (variety), `chat_top_k`, `prefer_long_replies`
