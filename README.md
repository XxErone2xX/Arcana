# Arcana

처음부터 만든 PC 비서 AI

사전학습 모델 없이, 트랜스포머(BERT/JointBERT 구조 참고)를 직접 구현하고 처음부터 학습시킨 명령형 비서야.
문장 하나 넣으면 **의도**(뭘 하라는 건지)랑 **슬롯**(앱 이름, 시간, 검색어, 메모 내용)을 같이 뽑아서 실행해.

## 설치 (윈도우)
1. Python 3.10 이상 설치 (설치할 때 "Add to PATH" 체크)
2. 이 폴더에서 cmd 열고:
   ```
   pip install -r requirements.txt
   ```
3. `실행.bat` 더블클릭 (또는 `python assistant.py`)
   - `python assistant.py -v` 로 실행하면 AI가 어떻게 판단했는지(의도, 확신도, 슬롯)도 보여줌

학습된 모델(`assistant_model.pt`)이 같이 들어있어서 바로 실행돼.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `model.py` | 트랜스포머 직접 구현 (멀티헤드 어텐션, 인코더 블록, 의도/슬롯 헤드) |
| `data.py` | 학습 데이터 생성기 (문장 템플릿 + 랜덤 단어) |
| `train.py` | 학습 스크립트 → `assistant_model.pt` 생성 |
| `skills.py` | 실제 기능 (앱 실행, 타이머, 메모 등) + 앱 목록 |
| `assistant.py` | 비서 실행 |

## 할 수 있는 말 예시
- `디코 켜줘`, `크롬 꺼`, `블렌더 실행해줘`
- `라면 3분 타이머`, `10분 있다 불러줘`
- `지금 몇 시야`, `오늘 며칠이야`
- `파이썬 딕셔너리 사용법 검색해줘`, `유튜브에서 페이커 하이라이트 틀어줘`
- `소리 키워`, `음소거`, `스샷`, `컴 잠가`, `컴퓨터 꺼줘` (끄기 전에 물어봄)
- `내일 체육복 챙기기 메모해줘`, `메모 보여줘`, `메모 다 지워`

## 앱 추가하기
`skills.py`의 `APPS`에 한 줄 추가하면 돼 (재학습 필요 없음):
```python
"포토샵": (r'"C:\Program Files\Adobe\Adobe Photoshop 2025\Photoshop.exe"', ["Photoshop.exe"]),
```
부르는 이름이 여러 개면 `ALIASES`에도 추가.
학습 데이터에 없는 앱 이름도 AI가 이름 부분은 뽑아내니까, APPS에만 등록하면 대부분 알아들어.
더 잘 알아듣게 하고 싶으면 `data.py`의 `APPS`에도 넣고 재학습해.

## 새 기능 추가하기
1. `data.py`의 `INTENTS`에 새 의도 이름 + 문장 템플릿 여러 개 추가
2. `skills.py`에 같은 이름의 함수 만들고 맨 아래 `SKILLS` 목록에 이름 추가
3. `python train.py` (CPU로 5~6분, 그래픽카드 있으면 훨씬 빠름)

## 성능
- 모델 크기: 약 85만 파라미터 (4층, 128차원, 헤드 4개)
- 학습 때 안 본 문장 테스트: 38개 중 37개 정답
- 한계: 학습 안 한 종류의 말(잡담, 지식 질문)은 못 하고 "못 배웠다"고 대답함.
  `계산기좀`처럼 동사 없이 이름만 말하면 가끔 못 알아들음.
